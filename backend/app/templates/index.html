Backups & export

Files are named <name>-yyyy.mm.dd.hh.mm. Your browser will ask where to save (on supported browsers).
Full ZIP = CSVs + thumbnails + database dump + linking manifest + README — portable to another machine and usable in any app.

E-book folder

Scans your e-book folder, reads each file's embedded metadata (EPUB, PDF, MOBI/AZW3, FB2, comics…) and catalogs it. Re-scanning is safe — files already in the catalog are skipped. Files are read in place; nothing is moved.

Import from CSV

Upload a CSV with any columns. Rows with an ISBN/ASIN or a title are eligible; pick which to add, choose Library or Wishlist (and a collection), optionally look up ISBNs online to fill metadata.

Library maps (3D)

The area prefix matches the start of your locations: Greece 12 → area Greece; UK 33 → area UK. Upload that area's standalone 3D-map HTML.

Custom catalogue sources (SRU)

Library of Congress and German DNB are built in (tick-boxes in Find a Match). To add others that speak SRU, paste the SRU search URL with {q} where the search term goes; it then appears as a tick-box in a book's Find a Match. Returns metadata; covers come from OpenLibrary by ISBN when available. Edit/remove any time.
British Library has no open SRU (services impaired since its 2023 cyber-incident); the Greek NLG exposes no public SRU — BiblioNet already covers Greek. Add either here if you obtain a working endpoint.
Ready-to-paste examples Library of Congress:
http://lx2.loc.gov:210/lcdb?version=1.1&operation=searchRetrieve&maximumRecords=10&recordSchema=marcxml&query=bath.any={q}
German National Library (DNB):
https://services.dnb.de/sru/dnb?version=1.1&operation=searchRetrieve&maximumRecords=10&recordSchema=MARC21-xml&query={q}
(Other SRU libraries: copy one of these and swap the host/path; keep {q}.)
